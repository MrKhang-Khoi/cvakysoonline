💡 HƯỚNG DẪN KẾT NỐI VÀ LƯU TRỮ TRÊN GITHUB

  1. Cách 1 (Khuyên dùng - 1 Click Đồng Bộ): Nhập thông tin giáo viên vào bảng → Bấm "☁️ Đồng Bộ Lên Firebase". Toàn bộ phần mềm máy tính trong trường sẽ tự động cập nhật danh sách ngay lập tức.
  2. Cách 2 (Lưu tệp trên GitHub): Bấm "📥 Tải File JSON" → Upload tệp school_roster.json lên Repository GitHub của bạn. Copy link raw (dạng https://raw.githubusercontent.com/.../school_roster.json) dán vào ô rosterUrl trong file workflow_config.json của ứng dụng.
  3. Cách 3 (Lưu trang HTML này trên GitHub): Đặt tên file là index.html hoặc admin_roster.html đưa lên GitHub Repo → Bật GitHub Pages để truy cập quản trị mọi lúc mọi nơi trên điện thoại, máy tính bảng hoặc máy tính giáo viên.

Thêm Giáo Viên Mới

Mật khẩu này dùng để giáo viên đăng nhập phần mềm Desktop (kết hợp với số CCCD). Quản trị viên có thể thiết lập mật khẩu riêng cho BGH hoặc đặt lại về 123456 khi giáo viên quên.

Giúp phần mềm phân biệt chính xác: BGH dùng USB Token phần cứng riêng để ký số hoặc dùng VGCA Cloud.

Khi được tích chọn, phần mềm sẽ kích hoạt nút "Đóng Dấu Cơ Quan (USB Token)" cho tài khoản này. Chỉ cấp cho Ban Giám hiệu, Văn thư hoặc người quản lý con dấu.
